## Root causes (5 whys)

**1. Little product work.** Why 4%? Of the 124 merges, 118 built or recorded the autonomy system: ADR 0011's
session types, the owner's process directions (#386, #398, #461, #466, #478, #508, #522), 9 ADRs and their TICK
text. Why did that work fill the milestone? It sat in M0, M0's gate needed it, and the Planner's work-mix budget
(ADR 0011 §3) only orders the queue; it never blocks, and M0's PLAN row had no product issue left to add. Why did
nothing move it out? Until ADR 0019 (#493, text in #533, merged today) a process issue chose the current milestone
by default. **Root:** process work had no milestone of its own that the exit path didn't need. ADR 0019 and `Ops`
are that fix, and M1's 29 open issues are product issues, so this retro adds no item and records 4% as the M1
baseline (action 3 measures it).

**2. Idle sessions cost a full orientation.** Why 169 k tokens for an `idle` exit? TICK §1 had each session read
LESSONS (42 KB), the newest journals, the owner feed (14 days of comments) and five GitHub lists before §2 ran the
scheduler. Why so many idle sessions? The driver starts a session every couple of minutes whatever the last pick
was, and on 11-27 and 11-28 no work was ready: issues waited for the Planner's next day (ADR 0015), for the owner, or
for a design window. **Root:** the cheap answer (`idle`) came last. Action 1 runs the scheduler first; a driver
back-off after an `idle` pick is a protected change and goes to an issue (#539).

**3. Rules over GitHub state draw one missed case per round.** Why did #479, #524, #528 and #530 reach the cap? Each
round's reviewer walked one more state the author had not tabulated (a feed kind's lifetime, a same-second close, a
reopen, a PR closing unmerged). Why weren't they tabulated? The template's self-check asks for a state table for
loop-bounding rules, but these are counts and filters over GitHub events, and the four LESSONS entries that said
"tabulate before round 1" (PRs #289, #312, #479, #524, #528) were read hours before the rule was written. **Root:**
same as retro 0002's root 2, for rules over GitHub state, which no checklist names. Action 2.
