  data leaving the machine);

  exact-boundary tests, spec/ADR/TICK drift, dead code).

## Main findings
1. **The owner feed and the ADR 0011 §7 endorsement rule track comments, not what they endorse (#263).** A review body
   edited after its "done:" reply never comes back, and a tagged issue's body can change after the owner's comment.
2. **Gates that pass when nothing ran (#262, #261).** The fuzz runner accepts an empty target list, a target with no
   libFuzzer "Done" line, and any `cargo-fuzz` that prints the pinned version; no test pins how `run` maps a crash
   to the exit status (AC.7). The same "what still passes" pattern as audits 0004 and 0005.
3. **Retro numbers trust unauthenticated text (#262 AS.3, #261).** Strangers' tagged comments count as reviews, and
   some date edges (a retro after `--until`, the overlap day, `+` rows) give wrong figures.
