## Main findings
1. **The owner-comment filter is not yet the guard's mirror (#216, #217).** The proposal's "starts with the tag"
   check and the guard's `lstrip().startswith` disagree on U+001C–U+001F, and the harness has no leading-whitespace
   agent case, so two plausible wrong versions of the check pass 71/71. The owner's PR #184 applies this proposal.
2. **The browser-test fixture watches one page (#218).** Popups, a second page and `request` traffic are unchecked,
   and any test can switch the checks off with `watch.allow`. The spec's "Not checked" list now says so.
3. **A typo in a tag drops a test from its ID silently (#218, CX.3).** `malformedTags` flags only tags that start
   with `@e2e`, so `@ee2.web.<id>` on a skipped test leaves the ID's other tests passing. Confirmed by reading
   `apps/web/e2e/journey-reporter.ts:50`.
4. **Harness boundary tests are weaker than their names (#218).** The over-1-MiB results test fails on a duplicate ID
   whatever the limit is; the stale-output `ci` tests can't see whether steps ran.
