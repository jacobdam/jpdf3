## 00:30 UTC #112 / PR #121 Web license check: close the audit 0002 bypasses
- Picked: d. #112 was the first security item in STATUS's order: CONSTITUTION 10 rests on the license check, and
  audit 0002 proved it could be bypassed. No owner items were open, main was green, and my own open PR #120 was
  green with auto-merge on (it merged during the session).
- Did:
  - apps/web/scripts/check-licenses.mjs and licenses-lib.mjs, plus spec specs/tooling/licenses.md. The check now
    refuses:
    - `src/` files without a lower-case scanned extension (`a.mod`, `c.JS`, `.pcss`, `README`);
    - `import.meta` other than `.env`;
    - `node_modules`, `/@fs/` and `/@id/` anywhere in a source's text;
    - scheme imports (`data:` and `file:` modules); only `data:`, `http(s):` and `mailto:` are allowed in asset
      positions;
    - any specifier character outside an allowlist (escapes, entities, `%`, whitespace, quotes);
    - `.`/`..` segments in package paths;
    - an `import(` that isn't a single literal;
    - `@jsx` pragmas.
  - Other scan changes:
    - quotes are paired by kind, and strings may span lines;
    - a line comment ends at CR, U+2028 or U+2029 too;
    - CSS and HTML forms match case-insensitively;
    - the scan also covers CSS `image-set` and HTML `srcset`, `poster` and og:image `content`.
  - Guards:
    - 31 vite.config keys;
    - csp.ts must have a fixed shape;
    - tsconfig.json must not use `jsxImportSource`, `extends`, `references` or `\u`;
    - no PostCSS config in the app directory or any parent.
  - The CC-BY data allowance now needs the exact registry tarball, a strict semver `version`, and a matching
    manifest version.

- Lesson:
  - A text scanner that guards a bundler has a bypass at every decoding layer and every file the tool loads on its
    own. Allowlist characters and shapes; never decode, never denylist. LESSONS updated.

    an env-var manager. Its only install hook was core-js's banner postinstall. I deleted it from the npx cache.
    LESSONS updated.
