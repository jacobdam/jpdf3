# Proposals for protected files

Agents can't change protected paths (CONSTITUTION 12). When a rule, the judge, CI or a guard
looks wrong, write `ops/proposals/<topic>.md` with:
- the problem, with evidence (links to runs/issues)
- the exact proposed diff
- the risk if it isn't applied

Keep working under the current rules meanwhile. Proposals are listed in the weekly digest.
The owner applies them (or not). Nothing waits on them.
