# Specs

- `specs/<area>/<feature>.md`: one per feature, from `_TEMPLATE.md`. Every checklist section
  is required (the judge checks).
- `specs/journeys/`: end-to-end user journeys. **The scope.** Append-only (CONSTITUTION 15).
- `specs/ui/`: UI information architecture and wireframes (macOS HIG, Material/MUI).
- `specs/TRACE.md`: PLAN §4 feature → journeys → specs → tests.
